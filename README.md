# Basic Image Gallery

A simple React image gallery project built to practice API fetching, state management, and Previous/Next navigation with a counter.

## Features

- 🖼️ Fetch images from an API
- ⬅️ Previous image button
- ➡️ Next image button
- 🔢 Image counter
- ⚛️ React state management
- 📱 Simple responsive UI

## Tech Stack

- React.js
- JavaScript
- CSS / Tailwind CSS
- REST API

## What I Learned

- Fetching data from an API
- Managing API data using React state
- Using `useEffect` for API calls
- Implementing Previous/Next functionality
- Managing image indexes with state

## Project Preview

A basic gallery where images are loaded from an API and users can navigate between them using Previous and Next buttons.
